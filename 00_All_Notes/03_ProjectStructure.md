# Spring Boot Project Directory Structure

When a Spring Boot project is created using **Spring Initializr**, the following directory structure is generated.

```text
myFirstJava
│
├── .idea/
├── .mvn/
│   └── wrapper/
│       └── maven-wrapper.properties
│
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── org/
│   │   │       └── rajbhar/
│   │   │           └── myfirstjava/
│   │   │               └── MyFirstJavaApplication.java
│   │   │
│   │   └── resources/
│   │       ├── static/
│   │       ├── templates/
│   │       └── application.properties
│   │
│   └── test/
│       └── java/
│           └── org/
│               └── rajbhar/
│                   └── myfirstjava/
│                       └── MyFirstJavaApplicationTests.java
│
├── .gitattributes
├── .gitignore
├── HELP.md
├── mvnw
├── mvnw.cmd
└── pom.xml
```

---

# Directory Explanation

## `.idea/`

This folder is automatically created by **IntelliJ IDEA**.

### Purpose

* Stores IntelliJ project settings.
* Contains IDE-specific configuration files.
* Not related to Spring Boot or Java code.

> **Note:** This folder is only useful when using IntelliJ IDEA.

---

## `.mvn/`

Contains files used by the **Maven Wrapper**.

### Purpose

* Allows anyone to build the project even if Maven is **not installed** on their computer.
* Downloads the required Maven version automatically.

Directory:

```text
.mvn/
└── wrapper/
    └── maven-wrapper.properties
```

The `maven-wrapper.properties` file specifies which Maven version should be downloaded.

---

## `src/`

This is the main source directory of the project.

It contains:

* Application source code
* Configuration files
* Static resources
* Unit tests

---

# `src/main/`

Contains the actual application code.

Everything required to run the application is located here.

---

## `src/main/java/`

This folder contains all Java source code.

Example:

```text
src/main/java/
└── org/
    └── rajbhar/
        └── myfirstjava/
            └── MyFirstJavaApplication.java
```

### Purpose

This is where you'll create:

* Controllers
* Services
* Repositories
* Entities
* DTOs
* Configuration classes
* Utility classes

Essentially, all Java classes for your application belong here.

---

## `MyFirstJavaApplication.java`

This is the **entry point** of the Spring Boot application.

Example:

```java
@SpringBootApplication
public class MyFirstJavaApplication {

    public static void main(String[] args) {
        SpringApplication.run(MyFirstJavaApplication.class, args);
    }

}
```

### Purpose

* Starts the Spring Boot application.
* Initializes the Spring container.
* Starts the embedded Tomcat server (if applicable).

---

## `src/main/resources/`

Contains all non-Java resources required by the application.

Examples include:

* Configuration files
* Images
* HTML templates
* CSS
* JavaScript
* Static assets

---

### `application.properties`

The main configuration file for the application.

Common configurations include:

```properties
server.port=8081

spring.datasource.url=...

spring.datasource.username=...

spring.datasource.password=...
```

Used to configure:

* Server settings
* Database connections
* Logging
* Security
* Spring Boot properties

---

### `static/`

Stores static files that are served directly by Spring Boot.

Examples:

* Images
* CSS files
* JavaScript files
* Fonts
* PDFs

Example:

```text
static/
├── logo.png
├── style.css
└── app.js
```

These files can be accessed directly through the browser.

---

### `templates/`

Stores server-side template files.

Common template engines include:

* Thymeleaf
* FreeMarker
* Mustache

Example:

```text
templates/
├── index.html
├── login.html
└── home.html
```

> **Note:** If you're building a REST API with React, Angular, or another frontend framework, this folder is generally not used.

---

# `src/test/`

Contains all test code.

Production code should **never** be placed here.

---

## `src/test/java/`

Contains unit and integration tests.

Example:

```text
src/test/java/
└── org/
    └── rajbhar/
        └── myfirstjava/
            └── MyFirstJavaApplicationTests.java
```

These tests are executed when running:

```bash
mvn test
```

---

# Root-Level Files

## `.gitattributes`

Defines Git attributes for files in the repository.

Used for:

* Line ending normalization
* Merge behavior
* File-specific Git settings

---

## `.gitignore`

Specifies files and folders that Git should ignore.

Common ignored items include:

* `target/`
* `.idea/`
* Log files
* Temporary files

This prevents unnecessary files from being committed to the repository.

---

## `HELP.md`

A documentation file generated by Spring Initializr.

Typically contains:

* Project information
* Useful links
* Spring Boot documentation

You may keep or remove this file as needed.

---

## `mvnw`

The Maven Wrapper script for **Linux** and **macOS**.

Run Maven commands without installing Maven:

```bash
./mvnw clean install
```

---

## `mvnw.cmd`

The Maven Wrapper script for **Windows**.

Run Maven commands without installing Maven:

```cmd
mvnw.cmd clean install
```

or

```cmd
.\mvnw clean install
```

---

## `pom.xml`

The most important file in a Maven project.

### Purpose

It defines:

* Project metadata
* Dependencies
* Plugins
* Build configuration
* Java version
* Spring Boot version

Example responsibilities:

* Adding dependencies like Spring Web or Spring Data JPA
* Managing project versions
* Configuring Maven plugins
* Packaging the application

Whenever you need to add a new library to your project, you'll typically modify the `pom.xml` file.

---

# Summary

| File/Folder              | Purpose                                               |
| ------------------------ | ----------------------------------------------------- |
| `.idea/`                 | IntelliJ IDEA configuration files                     |
| `.mvn/`                  | Maven Wrapper configuration                           |
| `src/main/java/`         | Application source code                               |
| `src/main/resources/`    | Configuration and static resources                    |
| `application.properties` | Application configuration                             |
| `static/`                | Images, CSS, JavaScript, and other static assets      |
| `templates/`             | Server-side HTML templates (e.g., Thymeleaf)          |
| `src/test/java/`         | Unit and integration tests                            |
| `.gitignore`             | Files and folders ignored by Git                      |
| `.gitattributes`         | Git file attributes configuration                     |
| `HELP.md`                | Spring Boot generated documentation                   |
| `mvnw` / `mvnw.cmd`      | Maven Wrapper scripts                                 |
| `pom.xml`                | Maven project configuration and dependency management |
